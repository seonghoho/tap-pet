개인정보처리방침

시행일: 2026년 10월 9일 · Tab Pet으로 돌아가기

Tab Pet(이하 "서비스")은 가입 없이 쓰는 브라우저 탭 펫입니다. 서비스는 이름, 이메일, 전화번호 같은 개인 식별 정보를 받지 않습니다. 아래는 서비스가 다루는 정보와 그 이유입니다.

1. 이 브라우저에만 저장하는 정보

펫 이름, 스탯, 성장 기록, 설정, 연속 돌봄 기록, 언어 설정은 사용자의 브라우저 저장소(localStorage)에만 저장되며 서버로 보내지 않습니다. 브라우저 데이터를 지우면 함께 사라집니다. "다른 브라우저로 옮기기"의 백업 코드도 사용자가 직접 복사해 붙여넣을 때만 이동하며, 서비스가 따로 보관하지 않습니다.

2. 선택적으로 수집하는 정보

항목목적처리 위탁끄는 방법
익명 사용 통계: 기능 사용 이벤트(예: 돌봄 종류, 레벨, 연속 일수), 페이지 방문, 브라우저 종류, 대략적 지역, 브라우저에 저장되는 무작위 식별자 어떤 기능이 쓰이는지 파악해 서비스 개선 PostHog Inc. 설정 › "익명 사용 통계 보내기" 끄기
오류 정보: 오류 내용, 발생 위치, 브라우저·OS 종류 오류 수정 Functional Software, Inc. (Sentry) 오류가 날 때만 전송되며, 입력 내용은 포함하지 않습니다

펫 이름, 백업 코드, 직접 쓴 탭 제목은 통계나 오류 정보에 포함하지 않습니다. 위 업체들은 해외(미국 등)에 서버를 두고 있어 정보가 국외로 이전될 수 있습니다. 통계 데이터는 수집일로부터 최대 1년간 보관 후 삭제합니다.

3. 결제

꾸미기 상품을 구매할 때 결제는 토스페이먼츠(주)의 결제창에서 이루어집니다. 카드 번호 등 결제 정보는 토스페이먼츠가 직접 처리하며 서비스는 받지 않습니다. 서비스는 결제 승인과 구매 복원을 위해 주문번호, 상품, 금액, 결제 상태만 확인하며, 구매 기록은 사용자의 브라우저에 저장됩니다. 전자상거래법에 따라 거래 기록은 토스페이먼츠에서 5년간 보관될 수 있습니다.

4. 브라우저 알림

설정에서 알림을 켜고 브라우저에서 허용한 경우에만, 탭이 열려 있는 동안 브라우저가 직접 알림을 띄웁니다. 서버 푸시나 알림용 연락처 수집은 없습니다. 브라우저 사이트 설정에서 언제든 끌 수 있습니다.

5. 크롬 확장 프로그램

Tab Pet 크롬 확장 프로그램은 펫 상태, 알림 설정, 백업 코드로 옮겨 온 구매 기록을 브라우저의 확장 저장소(chrome.storage.local)에만 저장합니다. 확장은 어떤 서버로도 정보를 보내지 않고, 사용 통계나 오류 정보도 수집하지 않으며, 방문한 웹사이트나 탭 내용을 읽지 않습니다. 확장을 삭제하면 저장된 정보도 함께 지워집니다.

6. 외부에서 불러오는 리소스

글꼴(Pretendard)을 jsDelivr CDN에서 불러옵니다. 이 과정에서 CDN이 접속 IP 등 일반적인 웹 요청 정보를 받을 수 있습니다. 친구 카드 이미지는 브라우저 안에서 만들어지며 서버로 보내지 않습니다.

7. 이용자의 권리

브라우저에 저장된 정보는 설정 › "처음부터 다시" 또는 브라우저 데이터 삭제로 언제든 지울 수 있습니다. 익명 통계의 열람·삭제를 원하시면 아래 연락처로 요청해 주세요. 확인 후 지체 없이 처리합니다.

8. 만 14세 미만 아동

서비스는 개인 식별 정보를 받지 않으며, 아동의 정보를 별도로 수집하지 않습니다.

English summary

Tab Pet has no accounts. Your pet lives only in this browser's localStorage. If enabled, anonymous usage events go to PostHog and error reports go to Sentry; pet names, backup codes and custom titles are never sent. You can turn off usage stats in Settings. Payments are handled by Toss Payments; we only see the order number, product, amount and status. Notifications are shown by your browser only after you allow them. Fonts load from jsDelivr. The Chrome extension keeps everything in chrome.storage.local, sends nothing anywhere, collects no usage or error data, and does not read the sites or tabs you visit.
