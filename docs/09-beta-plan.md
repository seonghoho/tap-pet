# 2주 클로즈드 베타 계획

목표는 하나다: 지금 감으로 정한 값들(30분 10회, 기본 업무 탭 모드, 쉬는 상태 기준 75, 가격)을 숫자로 확정하는 것. 새 기능은 베타 기간에 넣지 않는다.

## 1. 대상과 모집

- 규모: 100~300명. 이 정도면 퍼널 단계별 비율을 ±5%p 안쪽으로 볼 수 있다.
- 대상: 업무 중 브라우저를 오래 켜두는 직장인·학생 (1차 사용자 정의와 동일).
- 채널 예시: 사내/지인 슬랙·디스코드, 커뮤니티 1~2곳. 한 채널에 몰리면 편향되므로 2곳 이상.
- 공지에 담을 것: 링크 하나, "탭을 고정해두고 평소처럼 일해주세요", 의견 받을 곳 1개.

## 2. 시작 전 체크

- [ ] `docs/07-launch.md`의 배포 후 확인 항목 완료
- [ ] PostHog에 아래 대시보드 생성
- [ ] 의견 받을 곳 정하기 (구글 폼, 채널 등) — 정해지면 푸터에 링크 추가
- [ ] 결제는 테스트 키로 열지, 실제 키로 열지 결정 (가격 반응을 보려면 실제 키, 흐름만 보려면 테스트 키)

## 3. PostHog 대시보드

모두 `docs/06-analytics-events.md`의 이벤트로 만든다. 이벤트 이름 앞에 `tab_pet_`이 붙는다.

| 인사이트 | 종류 | 설정 |
| --- | --- | --- |
| 첫 주 퍼널 | Funnel | `pet_created` → `care_performed` → `pin_tip_dismissed` → (다음 날) `care_performed`, 전환 기간 7일 |
| 리텐션 | Retention | 시작: `pet_created`, 재방문: `care_performed` 또는 `return_visit`, 일 단위 |
| 주간 돌봄 일수 | Trends | `care_performed`, unique users per day, 주간 합산 |
| 횟수 제한 마찰 | Trends | `care_limit_reached` / `care_performed` (formula) |
| 충전 사용률 | Trends | `care_recharge_used` / `care_limit_reached` |
| 위장 모드 유지율 | Trends | `pet_created` 중 `title_mode=disguise` 비율, `title_mode_changed` 분해 |
| 쓰다듬기 | Trends | `pet_patted` unique users / 활성 사용자 |
| 공유 | Trends | `share_card_created` by `result` |
| 구매 | Funnel | `shop_viewed` → `checkout_started` → `purchase_completed` |

## 4. 판단 기준 (베타 끝나고 바로 적용)

| 지표 | 기준 | 그러면 |
| --- | --- | --- |
| 첫 돌봄 전환 (`pet_created` → 10분 안 `care_performed`) | 60% 미만 | 온보딩에서 첫 돌봄을 더 직접적으로 유도 (이름 짓기 직후 "밥 주기" 버튼 강조) |
| D1 리텐션 | 25% 미만 | 알림 기본값과 탭 고정 안내 위치 재검토 |
| D7 리텐션 | 10% 미만 | 크롬 확장 설치 유도를 웹에 추가 |
| 횟수 제한 도달 / 돌봄 | 세션의 30% 이상 | 30분 횟수 10 → 15로 상향 |
| 횟수 제한 도달 | 5% 미만 | 제한을 유지하되 충전 버튼 노출을 줄임 (수익화에 영향 없음) |
| 위장 모드에서 "기분 보여주기"로 바꾸는 비율 | 40% 이상 | 기본값을 "기분 보여주기"로 되돌리고 온보딩 질문 유지 |
| 쓰다듬기 사용자 비율 | 50% 이상 | 쓰다듬기에 작은 보상(하루 1회 친밀도) 검토 |
| 상점 조회 → 결제 시작 | 3% 미만 | 가격 또는 상품 구성 재검토 (꾸미기 팩 단독 1,900원 실험) |
| 결제 시작 → 완료 | 70% 미만 | 결제 흐름(카드만 → 간편결제 추가) 점검 |

## 5. 정성 피드백

- 2주차 중간에 5~8명 짧은 인터뷰 (15분): "회사에서 들킬 뻔한 적", "언제 탭을 보게 되는지", "귀여운 순간/귀찮은 순간".
- 의견 채널에 들어온 내용은 버그 / 사용성 / 캐릭터 반응 세 가지로만 분류.

2. 결과를 이 문서 아래에 기록
3. 크롬 확장 스토어 제출 (`docs/08-extension.md`)
